🐍 Python: от нуля до создания игр
1. Python 1 (с нуля)
• Возраст: от 10 лет
• Для учеников без опыта
• Основы синтаксиса, переменные, циклы, условия
• Формат: видеоуроки с заданиями и поддержкой
→ Подходит для тех, кто никогда не программировал, но хочет начать писать код

2. Python 2 (продолжение)
• Возраст: от 11 лет
• Ученик уже знаком с Python
• Функции, работа с файлами, проекты посложнее
→ Подходит для закрепления и расширения базовых знаний

3. Python в Minecraft
• Возраст: от 11 лет
• Для тех, кто хочет практиковать Python в игровой среде
• Игровой движок Minecraft + программирование робота
→ Увлекает тех, кто любит Minecraft и хочет кодить в игре

4. Pygame
• Возраст: от 12 лет
• Для продвинутых
• Создание игр на Python с использованием библиотеки Pygame
→ Идеален для учеников, которые хотят делать игры на Python

☕ Java: классика ООП + визуализация
Java с нуля
• Возраст: от 12 лет
• Стартовое изучение Java
• Темы: переменные, массивы, классы, графика, оконные приложения
→ В конце курса — создание игры «Змейка», работа с базами данных

🧱 Scratch: визуальное программирование по уровням
Scratch Level 1 (7–8 лет)
• Первый шаг в программировании
• Блочное мышление, условия, анимация
→ Без координат и дробей — только простые понятия

Scratch Level 2 (9–10 лет)
• Углубление: координаты, переменные, логические блоки
→ Для тех, кто прошёл уровень 1 или уже пробовал Scratch

Scratch Level 3 / Большое путешествие (9–13 лет)
• Программирование + география
• Уроки на английском языке + страны мира
→ Отлично подходит любознательным детям и любителям языка

Scratch: Наглядная математика (7–11 лет)
• Программирование + школьная математика
• Проценты, координаты, отрицательные числа
→ Идеально для повышения успеваемости в школе

⚒️ Разработка игр: визуально и на коде
Roblox Studio
• Возраст: от 9 лет
• Создание 3D-игр в Roblox
• Используется Lua и визуальный редактор Roblox Studio
→ Простой вход для тех, кто хочет делать игры

Unity блоки (11+ лет)
• Визуальная логика внутри Unity
• Подходит тем, кто ещё не готов писать код
→ Переходный этап к настоящему геймдеву

Unity C# (12+ лет)
• Полноценная разработка игр на Unity с использованием кода
→ Продвинутый курс, требует уверенности в синтаксисе

🧠 Искусственный интеллект (AI)
ИИ просто (13+ лет)
• Введение в мир нейросетей
• Обучение моделей, работа с данными
→ Подходит ученикам с интересом к современным технологиям и ИИ

⚙️ Аппаратное программирование
Arduino (11+ лет)
• Язык C++, работа с датчиками
• От виртуального моделирования до сборки робота
→ Подходит только тем, у кого уже есть опыт программирования

🎮 Minecraft: программирование через игру
Minecraft (7–13 лет)
• Программирование черепашки, стройка, квесты
• Осваиваются условия, циклы, логика
→ Любимый курс у фанатов игры

Логические задачи в Minecraft (5–6 лет)
• Визуальные задачки и простейшее управление
→ Без чтения, знакомство с кодированием через игру
