# Исправление проблемы с демо-ссылками

## 🚨 Проблема
Бот не использовал новый словарь ссылок для запросов о демо-уроках, потому что:
1. **Основной диалог шел через GPT** - пользователь писал "пришли демо роблокс", но это попадало в GPT, а не в наш обработчик
2. **Обработчик срабатывал только на точные команды** - "демо", "демо-уроки", но не на фразы типа "пришли демо роблокс"

## ✅ Что исправлено

### 1. Добавлена предварительная проверка в основной логике
```python
# Проверяем запросы о демо-уроках
if re.search(r'демо|демо-урок|демоурок', text, re.IGNORECASE):
    print(f"[DEBUG] Обнаружен запрос о демо: '{message.text}'")
    await handle_demo_callback_text(message, state)
    return

# Проверяем запросы о тарифах/ценах
if re.search(r'тариф|цена|стоимость|формат', text, re.IGNORECASE):
    print(f"[DEBUG] Обнаружен запрос о тарифах: '{message.text}'")
    await handle_price_callback_text(message, state)
    return
```

### 2. Улучшено распознавание названий курсов
```python
# Ищем курс после слова "демо" или похожих
demo_match = re.search(r'(?:демо|демо-урок|демоурок)[\s:,-]*([A-Za-zА-Яа-я0-9\- ]{2,})', user_text, re.IGNORECASE)

# Если не нашли, ищем курс в тексте
if not course_query:
    course_names = ["scratch", "python", "minecraft", "roblox", "java", "ai", "arduino", "unity", "веб", "web", "майнкрафт", "роблокс", "питон", "скретч", "джава", "ардуино", "юнити"]
    for course_name in course_names:
        if course_name in user_text.lower():
            course_query = course_name
            break
```

### 3. Добавлена отладочная информация
- Логирование обнаружения запросов о демо/тарифах
- Логирование найденных курсов
- Логирование результатов поиска в словаре

## 🔧 Как теперь работает

2. **Вызов**: `handle_demo_callback_text(message, state)`
3. **Поиск курса**: `re.search(r'(?:демо|демо-урок|демоурок)[\s:,-]*([A-Za-zА-Яа-я0-9\- ]{2,})', text)` находит "роблокс"
