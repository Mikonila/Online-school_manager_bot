# Codim.online — Telegram-бот-консультант по курсам программирования

Умный Telegram-бот, который помогает родителям, детям и преподавателям подобрать курс программирования в школе **Codim.online**.  
Под капотом — GPT-4o, векторная база знаний по всем курсам, правила подбора по возрасту и опыту и интеграция с Google Sheets.
Протестировать: https://t.me/codimonline_bot

---

## 🎯 Что умеет бот

### Для родителей и учеников

- Понимает свободный текст на русском:  
  «Сыну 10 лет, любит Minecraft, раньше ничего не программировал — что посоветуете?»
- Учитывает:
  - возраст ребёнка;
  - есть ли опыт в программировании;
  - чем занимался раньше (Scratch, Python и т.д.);
  - интересы: игры, ИИ, Telegram-боты, 3D, дизайн, роботы и др.
- Подбирает конкретные курсы с объяснениями:
  - название курса;
  - короткое описание «по-человечески»;
  - чем курс полезен ребёнку;
  - сколько уроков;
  - для какого возраста и уровня.
- Отдаёт прямые ссылки:
  - на страницу курса на сайте `codim.online`;
  - на демо-уроки на платформе.
- Показывает тарифы:
  - подписка на 30 дней;
  - PRO-доступ на 240 дней;
  - индивидуальные занятия (если есть для курса).
- Может быстро рассказать:
  - структуру программы;
  - пример проектов в рамках курса;
  - чем один курс отличается от другого (Scratch vs Minecraft vs Roblox и т.п.).

### Для преподавателей

Отдельный режим **«👨‍🏫 Я преподаватель»**:

- Задаёт вопросы про:
  - возраст группы;
  - опыт учеников;
  - желаемый стек (игры, Python, ИИ, 3D и т.д.).
- Подбирает:
  - готовые курсы и методические материалы;
  - варианты для очных и онлайн-занятий;
  - курсы «для учителя» (готовые методики + видеоуроки).
- Показывает:
  - демо-материалы;
  - тарифы для преподавателей;
  - ссылки на страницы с методиками.
- Может оформить запрос на консультацию — данные улетают менеджеру в таблицу.

### Интеллект и база знаний

- Использует **GPT-4o** через `openai` (клиент `AsyncOpenAI`).
- Работает не «вслепую», а на основе реальной базы знаний школы:
  - все курсы описаны в `bot/docs/courses_table.txt`;
  - тексты режутся на чанки и индексируются в **FAISS**;
  - semantic search делается через **LangChain**.
- Функция `search_knowledge()`:
  - ищет релевантные куски по запросу пользователя;
  - фильтрует курсы по возрасту и опыту (`is_course_suitable`);
  - отдаёт боту готовый контекст для GPT.
- Система промптов:
  - `bot/prompts/generator.md` — консультант по подбору курсов;
  - `bot/prompts/course_selection.md` — красивое оформление рекомендаций;
  - `generate_summary()` — короткое резюме диалога для менеджера.

## 🧠 Логика подбора курсов

В `bot/services/course_logic.py` описан набор **правил подбора**:

- Разные правила для возрастов: 5–7, 7–9, 9–12, 12+.
- Отдельные правила по интересам:
  - ИИ (`ai`) → сначала Python, потом курсы по ИИ и Telegram-ботам;
  - Telegram-боты (`tg_bots`);
  - игры (`games`) → Minecraft, Roblox, Unity;
  - 3D (`3d`) → Tinkercad, Arduino;
  - роботы (`robots`) → Arduino / Python;
  - языки программирования (`langs`) и др.
- Правила учитывают:
  - опыт («без опыта» / «есть опыт»);
  - стек («Scratch», «Python», «langs» и т.д.).

Результат: бот выдаёт не случайные курсы, а **осмысленный набор** вариантов, который соответствует возрасту, опыту и интересам ребёнка.

## 📊 Интеграция с Google Sheets

Модуль `bot/services/sheets.py`:

- Подключение по сервисному аккаунту (`gspread` + `google-auth`).
- Работа с несколькими таблицами:
  - основная таблица пользователей;
  - таблица курсов;
  - таблица тарифов.
- Возможности:
  - поиск строк по `Username` и `ID`;
  - обновление истории переписки («История переписки»);
  - запись резюме диалога;
  - фиксация заявок от преподавателей и родителей.

Преимущество: менеджер видит в таблице **готовое резюме диалога** + все нужные контакты и может быстро выйти на связь.
